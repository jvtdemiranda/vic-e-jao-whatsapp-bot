Projeto de portfólio · Automação com IA

Vic & Jão 🦐

Chatbot de atendimento para restaurante: mostra o cardápio, recebe o pedido, pergunta entrega ou retirada, gera o Pix e confirma — tudo em uma conversa natural, com memória do contexto.

Experimente: mande um “oi” no chat e faça um pedido de teste. Nenhum pedido ou pagamento é real.

Como funciona

  1. 1O cliente manda mensagem (aqui no navegador ou no WhatsApp).
  2. 2O backend junta a mensagem com o histórico recente da conversa.
  3. 3Um LLM (LLaMA 3.3 70B via Groq) responde seguindo o roteiro de atendimento do prompt.
  4. 4A resposta volta formatada no estilo WhatsApp (*negrito*, emojis, quebras de linha).

Tecnologias

  • n8n
  • Evolution API
  • Groq · LLaMA 3.3
  • Google Sheets
  • Node.js
  • Vercel Functions
  • Docker
